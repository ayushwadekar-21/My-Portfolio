# AyushVerse Portfolio

A Netflix-inspired responsive personal portfolio for Ayush Wadekar. It is a static site: no npm install, build command, or server is required.

## Deploy on Netlify
1. Extract `AyushVerse_Portfolio.zip`.
2. Sign in to Netlify and choose the manual deploy / drag-and-drop option.
3. Upload the extracted folder (or the `index.html` file).
4. Netlify will publish it and provide a public URL.

You can also upload these files to any static web host or enable GitHub Pages.

## Before publishing
- In `index.html`, replace `ADD-YOUR-EMAIL@example.com` with an email address you are comfortable making public. The contact link uses `mailto:`.
- Review the personal description and update any details you want.

## Files
- `index.html` — complete site with HTML, CSS, and JavaScript.
- `netlify.toml` — Netlify publish settings.
